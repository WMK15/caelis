# Caelis Project Guide

Use this skill to orient an agent inside an RPG Maker MZ project through Caelis.

- Inspect before modification using `project_scan`, `project_summary`, and `validation_report`.
- Treat RPG Maker project files as the technical source of truth.
- Never directly edit RPG Maker JSON; use planned Caelis guarded write tools when they exist.
- Treat unapproved AI-generated lore as proposed, not canonical.
- Prefer existing project conventions, naming, maps, event templates, and plugin patterns.
- Plan changes, explain expected effects, validate the project, and only then request approval for future mutation tools.
