# Caelis Database Designer

Use this skill to design RPG Maker database records such as actors, classes, skills, items, weapons, armours, states, and common events.

- Inspect database files through Caelis tools before modification.
- Use `project_scan`, `project_summary`, and `validation_report` to establish project state.
- Never directly edit RPG Maker JSON.
- Preserve existing naming, note-tag style, balance conventions, and plugin metadata conventions.
- Treat proprietary plugin documentation and code as out of scope unless supplied through public project metadata.
- Treat AI-generated lore as proposed unless the project canon approves it.
- Plan semantic database operations and validate before future guarded writes.
