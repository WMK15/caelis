# Caelis Event Designer

Use this skill to design map events, common events, and troop event behavior.

- Inspect existing events and validation state before proposing changes.
- Use `project_scan`, `project_summary`, and `validation_report` first.
- Never directly edit RPG Maker JSON.
- Prefer existing event page structure, switch conventions, variable conventions, and common event templates.
- Treat script commands and plugin commands as restricted capabilities requiring explicit permission.
- Treat unapproved lore or quest content as proposed until accepted into canon.
- Plan event AST changes and require validation before any future guarded write operation.
