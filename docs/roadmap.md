# Roadmap

## 1. Foundation

Create the monorepo, strict TypeScript packages, schemas, CLI, MCP server, tests, and CI.

## 2. Read-Only Project Intelligence

Expand project scanning, database indexing, search, graph relationships, asset metadata, reference validation, and plugin metadata extraction without executing plugins.

## 3. Safe Database Writes

Implement semantic database operations, preview rendering, backups, apply, and revert workflows.

## 4. Event AST And Compiler

Grow event command parsing and compilation through fixtures, including map events, common events, troop events, and plugin commands.

## 5. Codex Memory

Add durable local storage, source tracking, assertion status workflows, contradiction handling, and canon approval flows.

## 6. Plugin Adapters

Support native RPG Maker MZ and public third-party plugin integration boundaries through adapters.

## 7. Runtime Bridge

Implement the development-only playtest bridge with status, inspection, screenshots, safe runtime actions, and error reporting.

## 8. Desktop Hub

Provide a local desktop interface for scans, previews, approvals, Codex management, bridge sessions, and agent workflows.
